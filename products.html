Products

The released records, with their grids and files

The released records of each dataset, one per domain. Each grid has its own files: its grid description for cdo (grid_<GRID>.txt), its grid file (<GRID>_grid.nc) and the products. Download them with fesmdata.jl into $ICE_DATA/v2/<Domain>/<GRID>/ (see Getting started), or file by file from the links below.

Regions: regions and ice-sheet basins

Region codes (a hierarchy of hemispheres, continents, ice sheets and oceans), zones (open ocean, continental shelf, land) with the distance to the shelf break, and ice-sheet drainage basins extended to the shelf break, on the grids of a model domain. See how it is made.

Not released yet.

Topo: high-resolution topography

Bed topography, surface elevation, ice thickness and ice/ocean area fractions on the grids of a model domain, from the base grid to 32 km. Each source is remapped conservatively onto the base grid, the sources are merged in order of priority, and the coarser grids are derived from the base grid by conservative remapping. See how it is made.
